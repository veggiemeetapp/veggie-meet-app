## Licence / attribution

Artwork rendered from the **DiceBear "Notionists"** avatar style
(<https://dicebear.com>), original design by **Zoish**, released under
**CC0 1.0 Universal** (public domain dedication). No attribution is legally
required; this notice is retained for internal traceability.

Each avatar was rasterised **once** to a 512x512 PNG and is bundled as a hashed
same-origin build asset. The application makes **no runtime request** to the
DiceBear API or any other remote avatar host.

## Rejected artwork

The colourful generated WO-143 JPG set (`veggie-avatar-01.jpg` …
`veggie-avatar-08.jpg`) was **NOT PRODUCT APPROVED**. It has been removed from
`src/assets/avatars/` and from the application bundle, and is retained only
under `wo143/evidence/rejected-wo143-artwork-NOT-PRODUCT-APPROVED/` for
historical documentation. Candidates 8A, 8B, 8D, 8E and 8F were not selected.
